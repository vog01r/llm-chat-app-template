# AGENTS.md

## Cursor Cloud specific instructions

This is a **Cloudflare Workers** application ("Casus" — a French TTRPG assistant). Single service, no monorepo.

### Key commands

See `package.json` scripts:
- `npm run dev` — start local dev server on port 8787
- `npm run check` — TypeScript check + dry-run deploy
- `npm test -- --run` — run vitest (no test files exist yet; exits with code 1)
- `npm run cf-typegen` — regenerate `worker-configuration.d.ts` after changing `wrangler.jsonc`

### Development caveats

- **Cloudflare API token required for full dev**: `wrangler dev` needs `CLOUDFLARE_API_TOKEN` (and optionally `CLOUDFLARE_ACCOUNT_ID`) to enable the Workers AI binding. Without it, use `wrangler dev --local` — the server starts and serves static assets + local command handlers (`/roll`, `/help`), but the AI chat endpoint (`/api/chat` with LLM) will fail.
- **No ESLint configured** in this repo. Only TypeScript strict checking via `tsc --noEmit`.
- **No test files** currently exist. `npm test -- --run` exits 1 because vitest finds no test files.
- The `worker-configuration.d.ts` file is auto-generated and very large (~400K chars). Do not read it entirely; it is regenerated by `npm run cf-typegen`.
